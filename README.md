# Tableau Sales Dashboard

This project presents an interactive dashboard developed using Tableau to analyse and visualise sales data.

- Analyse important sales metrics.
- Identify trends and patterns.
- Present insights through interactive visualisations.
- Support data-driven decision-making.

## Dashboard Features

- Interactive filters and dashboard elements.
